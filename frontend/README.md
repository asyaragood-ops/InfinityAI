# infinityAI — фронтенд (Angular)

Чат-интерфейс с умным роутером нейросетей. Дизайн «Аврора», светлая и тёмная темы.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```bash
cd frontend
npm install
npm start          # откроет http://localhost:4200
```

Сборка для продакшена: `npm run build` → папка `dist/infinity-ai/browser`.

## Что внутри

| Раздел | Что умеет |
|---|---|
| **Чаты** | список чатов с поиском, выбор специализации и режима (авто-роутинг или конкретная модель), плашка при переключении модели, Enter — отправить |
| **Модели** | плитки / список, фильтр по специализациям, поиск, % лимита, прогресс-бар, таймер до сброса, меню (выключить, сбросить, удалить), окно «Добавить модель» |
| **Настройки** | API-ключи (показать / изменить), автопереключение, порог, стратегия выбора, контекст, уведомления, шифрование ключей — всё применяется бэкенд-роутером |

## Структура

```
src/app/
  core/            типы, сервисы (модели, чаты, роутер, тема, настройки), утилиты
  shared/          иконки, окно добавления модели, мини-markdown
  pages/chat       раздел «Чаты»
  pages/models     раздел «Модели»
  pages/settings   раздел «Настройки»
src/styles.css     дизайн-система (цвета обеих тем, кнопки, чипы, прогресс-бары)
```

## Каталог бесплатных моделей

`src/app/core/catalog.ts` — 326 моделей и сервисов с бесплатным лимитом или стартовыми кредитами (124 провайдера), данные на 19.10.2026.

- **API** — модель можно вызывать через API, её использует роутер. Достаточно указать один ключ провайдера в «Настройках».
- **Только сайт** — бесплатный лимит есть только в веб-версии сервиса; роутер такие модели пропускает, на карточке есть ссылка.
- Лимиты бесплатных тарифов часто меняются. Источники указаны в начале файла и в ссылке на каждой карточке.
- Файл генерируется скриптом: `python scripts/gen_catalog.py > src/app/core/catalog.ts`. Чтобы добавить или поправить модели, меняйте скрипт.

## Бэкенд

Чат отправляет сообщения в `POST /api/chat` бэкенда на C (`../backend`, см. его README). Dev-сервер Angular проксирует `/api` на `http://localhost:8080` (`proxy.conf.json`).

- Под ответом показывается бэйдж «Ответил: Gemini» — его присылает бэкенд вместе с текстом.
- Если ИИ №1 упёрся в лимит и ответил резервный, в чате появляется плашка «Лимит Gemini исчерпан → роутер переключил на GPT-4o».
- Если бэкенд не запущен, чат работает в демо-режиме (подсказка под полем ввода), ответы помечены «Демо».
- **API-ключи задаются только в «Настройках»**: при сохранении ключ сразу отправляется на бэкенд (`POST /api/keys`) и используется каскадом. Если бэкенд не запущен, ключ сохраняется в браузере и уходит на сервер автоматически, как только тот появится. Порядок каскада — в `backend/config.json`; модели каталога с введённым ключом попадают в каскад автоматически (на странице «Модели» у них пометка «в каскаде»).
- **Настройки роутера** сохраняются на бэкенде (`POST /api/settings`) и применяются к каждому запросу; включение/выключение моделей на странице «Модели» тоже сразу уходит на сервер. Без бэкенда настройки хранятся в браузере и отправляются при его запуске (кроме шифрования ключей — его включить можно только при работающем бэкенде).

Сбросить демо-данные: в консоли браузера выполнить `localStorage.clear()` и обновить страницу.
